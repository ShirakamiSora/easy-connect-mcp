# ADR-0001: Phase 0 technology baseline

- Status: accepted for Phase 0; protocol decision remains open where noted below.
- Date: 2026-07-28

Phase 0 uses TypeScript on Node.js, React for the web shell, PostgreSQL for the
local development database, and the official MCP TypeScript SDK at `1.30.0`.
The SDK probe is local-only and does not establish a complete MCP contract.

The `2025-11-25` probe is observed locally. Support for `2026-07-28` is
**DECISION REQUIRED** because SDK `1.30.0` does not export or negotiate that
protocol version. Phase 0 records this boundary and does not add custom
protocol framing or Phase 1 business behavior.
